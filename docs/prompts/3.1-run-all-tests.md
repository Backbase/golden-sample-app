## Run Tests

After all steps are implemented, run the complete test suite:

```bash
# Unit tests for the main journey
nx test [journey-project] --watch=false

# Unit tests for feature libraries
nx test [journey-project]-internal-feature-[feature-name] --watch=false

# Unit tests for data access
nx test [journey-project]-internal-data-access --watch=false

# E2E tests (with real backend if available)
nx e2e [journey-project]-e2e
```

# Unit tests
