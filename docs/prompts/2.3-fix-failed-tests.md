# 2.3 Fix Failed Tests

> **V-Model Stage:** 2.3 (Coding)  
> **Agent:** Implementation Agent  
> **Mode:** CREATE  
> **Trigger:** Tests from 2.2 fail

---

## Run Tests

```bash
nx test [project] --watch=false
```

---

## If Tests Pass

Proceed to commit:

```bash
git add .
git commit -m "feat([JIRA-ID]): step [N] - [description]"
```

Then continue to Step 2.1 for next step in execution plan.

---

## If Tests Fail

Use this prompt:

```
Act as the Implementation Agent from @docs/agents/implementation-agent.md in CREATE mode.

Test failed:

TEST: [test name]
ERROR: [error message]
STACK: [stack trace]

Rules:
1. Fix the IMPLEMENTATION, not the test
2. Only modify test if it has obvious bug
3. Explain what was wrong

Output corrected code.
```

---

## Gate

- [ ] All tests pass
- [ ] Implementation was fixed (not tests, unless test had a bug)

**If OK:** Commit and proceed to next step.
